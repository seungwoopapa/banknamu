숨은 보험금 찾기 내보험찾아줌 조회법

작성일 2026년 10월 1일
이 글의 금리·상품 조건·제도·수치는 2026년 10월 작성 시점 기준입니다. 현재 기준과 다를 수 있으니 실제 결정 전에는 해당 기관의 최신 안내를 확인해 주세요.

숨은 보험금은 생명보험협회·손해보험협회가 운영하는 내보험찾아줌(cont.insure.or.kr)에서 조회하면 됩니다. 공동인증서·IPIN·휴대폰·간편 인증 중 하나로 본인 확인을 거치면 가입한 생명보험·손해보험과 미청구보험금 내역이 한 번에 나와요.

2026년 10월 1일 확인 기준으로 숨은 보험금은 중도보험금, 만기보험금, 휴면보험금으로 나뉩니다. 조회 결과 화면에서 「미청구·휴면보험금 간편청구」를 누르면 청구까지 이어지고, 돈은 해당 보험회사가 본인 명의 계좌로 보냅니다.

금융위원회가 2026년 7월 7일 낸 보도자료를 보면 2025년 말 기준 숨은 보험금은 약 10조 3천억 원이에요. 중도보험금 7조 7,667억 원, 만기보험금 1조 9,235억 원, 휴면보험금 6,237억 원이고, 2025년 한 해 동안 찾아간 돈은 3조 2,470억 원(80만 건)이었습니다.

먼저 아래 표에서 무엇을 찾을 수 있는지 보고, 이어서 실제 조회 순서와 청구할 때 주의할 점을 설명드릴게요.

구분무엇을 의미하나조회 후 할 일
중도보험금보험기간 중 특정 시기 도래·생존 같은 조건을 채워 생긴 보험금(축하금, 자녀교육자금, 배당금 등)내보험찾아줌 간편청구 또는 보험회사에 청구
만기보험금만기 뒤 3년이 지나지 않아 소멸시효가 남은 보험금내보험찾아줌 간편청구 또는 보험회사에 청구
휴면보험금해지·실효 또는 만기 후 소멸시효(3년)가 지난 뒤에도 찾지 않은 환급금·보험금보험회사 또는 서민금융진흥원 지급 절차 확인

1. 내보험찾아줌 조회 대상

생명보험협회의 내보험찾아줌 안내에 따르면 보험가입 내역은 계약자 또는 피보험자로 등록된 생명보험·손해보험 계약을 기준으로 조회됩니다. 보험회사명, 상품명, 증권번호, 계약 상태, 보험기간 같은 정보가 표시됩니다.

미청구보험금은 보험금 지급 사유가 발생했고 지급 금액도 정해졌지만, 청구하지 않았거나 지급되지 않은 내역입니다. 결과 화면에서 보험금 유형, 금액, 가산이자, 계약 관계를 확인할 수 있어요.

다만 새마을금고, 우체국, 신협, 수협 등에서 가입한 공제(보험)상품은 내보험찾아줌에서 조회되지 않습니다. 이 상품까지 찾으려면 해당 기관에 따로 문의해야 하네요.

2. 본인인증부터 결과 확인

조회는 내보험찾아줌 공식 사이트(cont.insure.or.kr, 손해보험협회 쪽 주소는 cont.knia.or.kr)에서 진행합니다. 첫 화면의 「내 보험 찾아줌 조회하기」를 누르면 정보동의, 본인인증, 결과확인 3단계로 이어져요.

본인인증 단계에서 이름과 주민등록번호 등을 넣고 공동인증서·IPIN·휴대폰·간편 인증 중 하나를 고르세요. 인터넷 조회는 365일 24시간 되고, 결과는 신청일부터 1개월 동안 다시 볼 수 있습니다.

  1. 내보험찾아줌 공식 사이트 주소를 직접 입력해 접속
  2. 「내 보험 찾아줌 조회하기」 선택
  3. 정보동의: 개인(신용)정보·고유식별정보 수집·이용·조회·제공 동의
  4. 본인인증: 이름·주민등록번호 등 입력 후 공동인증서·IPIN·휴대폰·간편 인증 중 선택
  5. 결과확인: 보험가입 내역, 미청구보험금, 휴면보험금 조회 결과 확인

온라인 인증이 어렵다면 협회 지역본부·지부를 찾아가 신분증을 내고 조회하면 됩니다. 서울 퇴계로의 생명보험협회 본부는 조회 업무를 하지 않으니, 서울에서는 생명보험협회 수도권본부(종로구 김상옥로)나 손해보험협회 통합민원지원센터(금천구 벚꽃로)로 가세요.

만 14세 미만은 법정대리인이 방문해야만 조회되고, 사망자의 보험 내역은 일반 온라인 조회가 아니라 상속인 조회 절차를 따릅니다.

3. 조회 결과에서 금액 읽는 법

결과 화면에 금액이 보인다고 해서 모두 같은 성격의 돈은 아닙니다. 상법 제662조는 보험금청구권을 3년간 행사하지 않으면 시효로 소멸한다고 정하고 있고(2015년 3월 12일 이전에 생긴 사유는 2년), 이렇게 시효가 끝난 돈이 휴면보험금이거든요.

시효가 끝났다고 돈이 사라지지는 않습니다. 휴면보험금은 보험회사나 서민금융진흥원이 보관하고 있어서 지금도 찾아갈 수 있어요.

금융위원회 보도자료에 붙은 FAQ는 현행 생명보험 표준약관 기준 예시로 만기 뒤 1년간 평균공시이율의 50%, 그다음 2년간 40%의 이자를 안내합니다. 실제 이자는 계약 시점과 상품 약관마다 다르고, 휴면보험금에는 이자가 전혀 붙지 않습니다.

조회 금액이 곧 입금액은 아닙니다. 결과 화면의 금액은 보험회사 산출일 기준이라, 보험계약대출 원리금이나 세금이 공제되면 실제 수령액이 달라지거든요.

그래서 보험회사에 연락할 때는 보험금 유형, 원금, 가산이자, 실제 지급 예정액을 각각 물어보세요.

4. 조회 후 보험금 청구 순서

조회 결과 화면의 「미청구·휴면보험금 간편청구」 버튼을 누르면 보험회사 홈페이지에 따로 가입하지 않고 여러 건을 골라 한 번에 청구하면 됩니다. 2021년 11월 3일부터 생긴 기능이고, 돈은 해당 보험회사가 본인 명의 계좌로 보냅니다.

공식 안내상 간편청구 뒤 3영업일 안에 보험회사가 보험금을 보내거나 전화를 겁니다. 추가 서류가 필요하거나 보험회사에 등록된 기존 거래 계좌가 아니면 전화 확인을 거치는데, 이때 전화 연결이 안 되면 청구가 취소될 수 있어요.

  1. 조회 결과에서 보험회사·보험금 유형·금액 확인
  2. 「미청구·휴면보험금 간편청구」 선택 후 개인정보 동의와 간편청구 위임 동의
  3. 청구할 보험금 선택
  4. 예금주 이름·생년월일·은행명·계좌번호·휴대폰번호 입력(본인 명의 계좌만 가능)
  5. 「청구 신청」 뒤 3영업일 안에 입금이나 보험회사 전화 확인

신청을 마치면 취소나 정정이 안 되니 계좌번호를 한 번 더 보세요. 계약자이지만 보험금 청구권자가 아니거나 수익자가 지정되지 않은 계약은 조회만 되고 간편청구가 막힐 수 있어서, 이때는 보험회사 콜센터로 청구해야 합니다.

휴면보험금은 누가 보관하느냐에 따라 신청처가 갈립니다. 보험회사가 아직 가진 휴면보험금은 보험회사나 내보험찾아줌에서, 서민금융진흥원에 이미 출연된 휴면보험금은 서민금융진흥원 휴면예금 안내에 나온 휴면예금찾아줌·서민금융 잇다 앱·서민금융콜센터 1397 등으로 신청하세요.

5. 조회되지 않거나 청구가 막힐 때

보험에 가입한 기억이 있는데 결과에 나오지 않는다면 공제상품인지 먼저 확인하세요. 우체국, 신협, 수협, 새마을금고 등에서 가입한 보험·공제상품은 조회 내용에 들어가지 않습니다.

보험금·환급금 지급이 끝난 계약은 계약 종료 뒤 3년까지만 가입 내역에 나와요. 압류나 지급정지가 걸린 계좌에 해당하는 미청구보험금도 조회 결과에서 빠지니 보험회사에 직접 물어보세요.

보험가입 내역은 계약자·피보험자 기준으로, 미청구보험금은 그 계약의 계약자와 수익자 기준으로 조회됩니다. 피보험자이기만 하면 계약은 보여도 미청구보험금은 안 보일 수 있으니, 보험증권이나 보험회사 상담으로 수익자를 다시 확인하세요.

사망자의 보험을 찾는 상황이라면 먼저 금융감독원 「상속인 금융거래조회 서비스」나 「안심상속 원스톱 서비스」를 신청해야 합니다. 안심상속은 사망일이 속한 달의 말일부터 1년 안에 정부24나 주민센터에서, 상속인 금융거래조회는 금감원·은행·우체국 등 접수처에서 신청하고요.

신청 뒤에는 내보험찾아줌 첫 화면의 「상속인 방문조회 신청결과 확인하기」에서 접수번호와 상속인 본인인증으로 결과를 봅니다. 다만 망인의 숨은 보험금 청구는 내보험찾아줌에서 되지 않으니 해당 보험회사에 문의하세요.

서민금융진흥원에 출연된 휴면보험금이 2천만 원을 넘거나, 망인 명의이거나, 개명한 경우에는 전화·인터넷·모바일 환급 신청이 제한될 수 있습니다. 이때는 서민금융통합지원센터를 찾아가거나 서민금융콜센터 1397에 먼저 문의하세요.

6. 내보험찾아줌 조회 체크리스트

숨은 보험금을 미끼로 한 연락도 조심해야 합니다. 금융감독원은 2026년 7월 1일 '찾지 못한 숨은 보험금 무료 안내' 같은 광고로 개인정보 제공 동의를 받아 보험 영업에 쓰는 사례에 소비자경보(주의)를 냈어요.

금융위원회 FAQ도 내보험찾아줌은 입력한 개인정보를 마케팅에 쓰지 않는다며, 조회 뒤 보험 권유 전화가 오면 유사 사이트를 의심하라고 안내합니다. 문자나 광고 속 링크보다 주소를 직접 입력해 들어가는 편이 안전하죠.

  • 주소가 cont.insure.or.kr 또는 cont.knia.or.kr인지 확인
  • 공동인증서·IPIN·휴대폰·간편 인증 중 가능한 수단 준비
  • 중도보험금·만기보험금·휴면보험금 유형 구분
  • 보험회사명, 증권번호, 금액, 가산이자 기록
  • 간편청구는 본인 명의 계좌로만, 신청 뒤 취소·정정 불가
  • 우체국·신협·수협·새마을금고 상품은 해당 기관에 별도 확인
  • 사망자 보험은 상속인 금융거래조회나 안심상속 신청 뒤 조회

가장 먼저 할 일은 내보험찾아줌에서 조회하고 결과를 기록해 두는 것입니다. 그다음 간편청구로 끝내거나, 막히는 건은 보험회사 또는 서민금융진흥원 절차로 청구하면 됩니다.

조회 금액이 작아 보여도 휴면보험금은 이자가 붙지 않으니 미루지 않는 편이 낫습니다. 다만 화면에 표시된 금액과 실제 지급액이 다를 수 있어 최종 금액은 지급기관에 확인하세요.
